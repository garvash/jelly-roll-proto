# 03-04-PLAN: Juice Polish & Final Verification

## Objective
Finalize Phase 3 by adding "juice" effects (hit-stop and screen shake) to the environmental interactions and conducting a full phase verification (`ENV-01`, `DRILL-02`).

## Context
Waves 1-3 implement the core functionality (Hazards and Destructible Blocks). Wave 4 (this plan) adds the "feel" and polish that makes the Drill Dive impact satisfying.

## Implementation Steps

### Task 1: Screen Shake & Hit-Stop in Game
- In `main.py` `Game.__init__`, add `self.shake_timer = 0` and `self.stop_frames = 0`.
- In `Game.update`, decrement `stop_frames` and return early if `> 0`.
- In `Game.draw`, use `pyxel.camera(dx, dy)` with random offsets if `shake_timer > 0`.

### Task 2: Triggering Effects on Impact
- In `src/entities/player.py` `on_block_break()`, set the game instance's `shake_timer` and `stop_frames`.
- Use `DRILL_SHAKE_DURATION` and `DRILL_HITSTOP_FRAMES` constants (add to `src/core/constants.py`).

### Task 3: Final Phase Verification
- Conduct full testing across hazards, blocks, and polish.
- Update `ROADMAP.md` and `STATE.md`.

## Verification Strategy

### Automated Tests
- Verification of logic-freeze in `main.py` (optional).

### Manual Verification
- Run `python main.py`.
- Break blocks and observe satisfying "crunchy" feedback from screen shake and hit-stop.
- Verify hazards still function correctly alongside juice.
