# 03-03-PLAN: Destructible Blocks & Drill Interaction

## Objective
Enable the Drill Dive to interact with the environment by breaking specific "soft" blocks, opening new pathways and providing a resource-reward loop (`DRILL-02`).

## Context
Phase 2 introduced the Drill Dive and slime juice. Phase 3 Wave 1 (03-01) prepares tile identification for destructible tiles. This wave adds the removal logic and the juice reward.

## Implementation Steps

### Task 1: Detect Destructible Tiles on Impact
- Update `src/entities/player.py` `move_and_collide` to check `self.level_map.is_destructible` when in `DIVING` state.
- Identify the tile coordinates (tx, ty) of the hit block.

### Task 2: Tile Removal in LevelMap
- Update `src/level/map.py` to include `remove_tile(tx, ty)`.
- Use `pyxel.tilemap(0).set(tx, ty, (0, 0))` to clear the tile.

### Task 3: Juice Refund Logic
- In `Player.move_and_collide`, when a block is hit:
  - Call `self.level_map.remove_tile(tx, ty)`.
  - Call `slime.refill(DRILL_BLOCK_REFUND)` (add constant to `src/core/constants.py`).
  - Trigger `self.on_block_break()` (prep for wave 4 polish).

## Verification Strategy

### Automated Tests
- Create `tests/test_destruction.py`.
- **Test 1:** Verify tile at (tx, ty) is NOT (0, 0) before impact.
- **Test 2:** Trigger Drill Dive into the tile and verify it becomes (0, 0) after.
- **Test 3:** Verify slime juice increases after block destruction.

### Manual Verification
- Run `python main.py`.
- Locate a destructible block (marked in Wave 1).
- Drill into it.
- Confirm it disappears and juice replenishes slightly.
