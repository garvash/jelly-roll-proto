# Plan 05-02: Basic Enemies (Snail & Bat)

Implement the enemy base class and two specific enemy types with simple AI.

## User Review Required

> [!IMPORTANT]
> - Snail enemies will turn around at ledges and walls.
> - Bat enemies will hang on the ceiling and dive when the player is beneath them.

## Proposed Changes

### Enemy Base Class (`src/entities/enemies.py`)
- Define `Enemy` with `hp`, `x`, `y`, `w`, `h`, `is_alive`.
- Methods: `update(player, level_map)`, `draw()`, `take_damage()`.

### Snail Enemy
- Horizontal movement.
- Ledge detection: if moving right and there's no ground ahead, turn left.
- Wall detection: if moving right and hit a wall, turn left.

### Bat Enemy
- Ceiling state: stay at initial Y.
- Dive state: if `abs(player.x - self.x) < 64` and `player.y > self.y`, dive down.
- Return state: fly back up to ceiling after dive.

### Spawning (`main.py`)
- Add `spawn_enemies()` method to scan the current room for enemy spawn tiles.
- Tile (1, 2) -> Snail.
- Tile (2, 2) -> Bat.

### Combat Integration
- **Slime Spit**: Check collision with enemies.
- **Drill Dive**: Check collision with enemies.
- **Player Contact**: Call `player.take_damage()` if not invulnerable.

## Verification Plan

### Automated Tests
- `test_snail_turn_at_wall`: Verify snail reverses direction.
- `test_snail_turn_at_ledge`: Verify snail reverses direction.
- `test_bat_dive_logic`: Verify bat triggers dive when player is close.
- `test_enemy_death`: Verify enemies die when hit by projectile or drill.

### Manual Verification

- Stand under a bat: should dive at you.
