With:
```python
# Draw tilemap layers in z-order with parallax scroll (TILE-06, D-06, D-09)
layers = schema.get_layers()
for layer in sorted(layers, key=lambda l: l["z"]):
    scroll = layer["scroll"]
    pyxel.camera(int(offset_x * scroll), int(offset_y * scroll))

# Restore camera to 1.0 scroll rate for entity drawing (Pitfall 7)

```

IMPORTANT: The `int()` cast on camera offsets prevents sub-pixel jitter at non-integer scroll rates.

IMPORTANT: The `pyxel.camera(offset_x, offset_y)` restore line MUST come after the loop and BEFORE any entity drawing (boss, enemies, items, stains, etc.). This ensures entities render at the correct positions.

Remove the previous `pyxel.camera(offset_x, offset_y)` line that was before the old single bltm call (line 788), since the camera is now set per-layer inside the loop and restored after.

The final structure of _draw_game_world should be:

    pyxel.clip(0, 0, VIEWPORT_W, VIEWPORT_H)
    offset_x = self.cam_x
    offset_y = self.cam_y
    if self.shake_timer > 0:
        offset_x += pyxel.rndi(-2, 2)
