    Create `src/core/schema.py` as a module-level singleton (per D-01, D-03). No class needed -- module globals + functions.

    Module structure:

    ```python
    import json
    import os

    _schema = None
    _val_to_tile = None
    _behavior_sets = None
    _hazard_drain_map = None
    _tileset_path = None
    _layers = None

    def init(schema_path="assets/entity-schema.json"):
        """Load schema and build all lookup structures. Call once at startup.
        Raises RuntimeError if file missing or malformed (D-02)."""
        global _schema, _val_to_tile, _behavior_sets, _hazard_drain_map, _tileset_path, _layers
        if not os.path.exists(schema_path):
            raise RuntimeError(f"Schema file not found: {schema_path}")
        try:
            with open(schema_path) as f:
                _schema = json.load(f)
        except (json.JSONDecodeError, OSError) as e:
            raise RuntimeError(f"Failed to parse schema: {e}")
        _build_lookups()

    def _build_lookups():
        global _val_to_tile, _behavior_sets, _hazard_drain_map, _tileset_path, _layers
        biome = "cavern"  # D-11: hardcoded active biome
        tile_coords = _schema["biomes"][biome]["tile_coords"]
        
        # Build val_to_tile: int -> (col, row) tuple
        _val_to_tile = {}
        for key, coords in tile_coords.items():
            if key == "description":
                continue
            _val_to_tile[int(key)] = tuple(coords)
        
        # Build behavior sets from intgrid.values
        _behavior_sets = {
            "collision": set(),
            "destructible": set(),
            "damage": set(),
            "zone_hazard": set(),
            "interactive": set(),
        }
        for key, entry in _schema["intgrid"]["values"].items():
            val = int(key)
            behavior = entry.get("behavior", "none")
            if behavior == "none":
                continue
            for part in behavior.split("+"):
                if part in _behavior_sets:
                    _behavior_sets[part].add(val)
        
        # Build hazard drain map: IntGrid int -> drain string
        _hazard_drain_map = {}
        for key, entry in _schema["intgrid"]["values"].items():
            if "drain" in entry:
                _hazard_drain_map[int(key)] = entry["drain"]
        
        # Tileset path and layers
        _tileset_path = _schema["biomes"][biome]["tileset"]
        _layers = _schema["biomes"][biome]["layers"]
    ```

    Public API functions (all raise if init() not called):

    - `get_val_to_tile()` -> dict[int, tuple[int,int]]: Returns IntGrid value to (col,row) mapping
    - `get_solid_values()` -> set[int]: IntGrid values with "collision" behavior
    - `get_hazard_values()` -> set[int]: IntGrid values with "damage" behavior
    - `get_zone_hazard_values()` -> set[int]: IntGrid values with "zone_hazard" behavior
    - `get_destructible_values()` -> set[int]: IntGrid values with "destructible" behavior
    - `get_interactive_values()` -> set[int]: IntGrid values with "interactive" behavior
    - `get_hazard_drain_map()` -> dict[int, str]: IntGrid value to drain string ("slow"/"medium"/"fast")
    - `get_tileset_path()` -> str: Active biome tileset PNG path
    - `get_layers()` -> list[dict]: Active biome layer definitions

    Per D-02: No fallback. Missing/malformed file = RuntimeError.
    Per D-11: Hardcode "cavern" as active biome.
