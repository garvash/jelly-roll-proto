# Phase 11 — UI Design Contract

> Visual and interaction contract for Save System and HUD elements. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Pyxel 2.8.2 retro engine) |
| Preset | not applicable |
| Component library | none (custom pixel-art rendering via `pyxel.rect`, `pyxel.text`, `draw_sprite`) |
| Icon library | none (inline pixel art, Pyxel palette colors) |
| Font | Pyxel built-in 4x6 bitmap font (`pyxel.text()`) |

---

## Spacing Scale

All spacing in whole pixels. Pyxel renders at 320x192 with no sub-pixel support.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 1px | Pixel-art detail gaps, 1px borders |
| sm | 2px | Inner pip padding, mini-map room gaps |
| md | 4px | HUD element margins, text padding from edges |
| lg | 8px | Element size base unit (HP pip = 8x8, juice bar h = 8) |
| xl | 16px | HUD strip height, section breaks on pause screen |
| 2xl | 24px | Pause screen section spacing (map to stats gap) |
| 3xl | 32px | Title screen vertical rhythm between title and menu |

Exceptions:
- HP pip stride: 10px (8px pip + 2px gap) -- existing pattern from `_draw_hud()`
- Mini-map room squares: 3px per standard room width, proportional height -- derived from world bounds

---

## Typography

Pyxel has a single built-in bitmap font: 4px wide x 6px tall, monospaced. No weight or size variation. All text differentiation is through **color** and **position**.

| Role | Rendering | Color (Pyxel palette) | Usage |
|------|-----------|----------------------|-------|
| Title | `pyxel.text()` uppercase, centered | 7 (white) | Title screen game name "JELLY ROLL" |
| Menu item (selected) | `pyxel.text()` | 7 (white) | Active menu option on title/pause screens |
| Menu item (unselected) | `pyxel.text()` | 5 (dark gray) | Inactive menu options |
| HUD label | `pyxel.text()` | 7 (white) | Any future HUD text labels |
| Prompt | `pyxel.text()` centered above entity | 10 (yellow) | "SAVE?" prompt above save point |
| Cursor | `pyxel.text()` ">" prefix, 8px left of menu item | 10 (yellow) | Menu selection indicator |

Text centering formula: `x = (SCREEN_W - len(text) * 4) // 2`

## Color

Pyxel uses a fixed 16-color palette. No hex values -- all colors referenced by palette index.

### Surface Colors

| Role | Palette Index | Pyxel Color | Usage |
|------|---------------|-------------|-------|
| Background (dominant) | 0 | Black | Screen clear on title, death fade, pause overlay base |
| HUD surface | 1 | Dark blue | HUD strip background (existing: `_draw_hud()` line 603) |
| Pause overlay | 0 | Black | Full-screen overlay behind pause content |

### Interactive / Status Colors

| Role | Palette Index | Pyxel Color | Reserved For |
|------|---------------|-------------|--------------|
| Primary text | 7 | White | All readable text, selected menu items, HP pip borders |
| Accent | 10 | Yellow | Save point pulse, menu cursor ">", save prompt text |
| Health filled | 8 | Red | Filled HP pips (existing) |
| Health empty | 5 | Dark gray | Empty HP pips, unselected menu items, juice bar background |
| Juice fill | 11 | Green | Juice meter bar fill (existing) |
| Juice border | 7 | White | Juice meter border (existing) |

### Mini-Map / Macro-Map Colors (from D-08)

| Room Type | Palette Index | Pyxel Color | Rendering |
|-----------|---------------|-------------|-----------|
| Visited (normal) | 5 | Dark gray | Filled rectangle |
| Current room | 7 / 0 | White / Black | Blink: alternate every 15 frames (`frame_count % 30 < 15`) |
| Save room | 11 | Green | Filled rectangle (matches juice color for "safe" association) |
| Boss room | 8 | Red | Filled rectangle (matches HP damage color for "danger" association) |
| Unvisited | -- | -- | Not drawn (invisible per D-07) |

### Save Point Entity Colors

| State | Palette Index | Pyxel Color | Rendering |
|-------|---------------|-------------|-----------|
| Pulse bright | 10 | Yellow | Primary sprite/rect color, visible 30 of 60 frames |
| Pulse dim | 9 | Orange | Alternate color, visible 30 of 60 frames |

Accent (palette 10 yellow) reserved for: save point pulse, menu cursor indicator, save prompt text, save room marker on map. Never used for enemies, health, or juice.

## Copywriting Contract

| Element | Copy | Context |
|---------|------|---------|
| Title screen heading | `JELLY ROLL` | Centered horizontally, y=60 |
| Title: continue option | `CONTINUE` | Shown only when `SaveManager.exists()` returns True |
| Title: new game option | `NEW GAME` | Always shown; sole option when no save exists |
| Save prompt | `SAVE?` | Displayed above save point when player overlaps; disappears when player moves away |
| Save confirmation | `SAVED!` | Flash for 60 frames (1 second) after successful save, then disappear |
| Pause: resume | `RESUME` | First menu item on pause screen |
| Pause: save (conditional) | `SAVE` | Second menu item, shown only when player is in a save room |
| Pause: quit | `QUIT` | Last menu item; returns to title screen |
| Death: no copy | (none) | Death sequence is visual only -- freeze + fade to black, no text |
| Empty world state | (not applicable) | No empty states in this phase; world always has rooms |

### Destructive Actions

| Action | Confirmation Approach |
|--------|----------------------|
| New Game (when save exists) | Show `ERASE SAVE AND START OVER?` with `YES` / `NO` options. Cursor defaults to `NO`. |
| Quit from pause | No confirmation -- returns to title; save data is not erased |

## Component Inventory

### 1. Title Screen (`_draw_title`, `_update_title`)

| Property | Value |
|----------|-------|
| Background | `pyxel.cls(0)` black |
| Title position | Centered x, y=60 |
| Menu start y | y=100 |
| Menu item spacing | 12px vertical between options |
| Cursor | ">" character, palette 10, 8px left of menu text x |
| Input | UP/DOWN arrows cycle `title_cursor`, Z/ENTER confirms selection |
| Gamepad | D-pad up/down, A button confirms |

### 2. Save Point Entity (`SavePoint`)

| Property | Value |
|----------|-------|
| Collision box | 8x8 pixels (matches TILE_SIZE) |
| Visual size | 16x16 pixels (SPRITE_SCALE=2) or 8x8 rect placeholder |
| Pulse cycle | 60 frames total: 30 frames palette 10 (yellow), 30 frames palette 9 (orange) |
| Proximity check | AABB overlap between player hitbox and save point hitbox |
| Interaction trigger | Player overlapping + UP key pressed (`btnp(pyxel.KEY_UP)`) |
| Prompt display | "SAVE?" in palette 10, centered above entity, y = entity.y - 8 |
| Save feedback | "SAVED!" in palette 10, same position, displayed for 60 frames then cleared |

### 3. Mini-Map HUD Element (`_draw_minimap`)

| Property | Value |
|----------|-------|
| Position | Centered in HUD strip: x=54 to x=236 (182px available), y=VIEWPORT_H (176) |
| Map centering | Center the scaled world bounds within the 182px available width and 16px height |
| Room scale | Proportional: compute scale factor so entire world fits within ~60px wide x 12px tall |
| Room min size | 2px width, 1px height minimum per room rectangle |
| Room gap | 1px between adjacent rooms |
| Border | 1px white (palette 7) rectb around entire mini-map area |
| Colors | Per mini-map color table above |
| Blink rate | Current room: 15 frames on (white), 15 frames off (black), using `pyxel.frame_count % 30 < 15` |

### 4. Pause Screen Overlay (`_draw_pause_overlay`, `_update_pause`)

| Property | Value |
|----------|-------|
| Background | Draw frozen game world first, then `pyxel.rect(0, 0, SCREEN_W, SCREEN_H, 0)` black overlay |
| Macro-map position | Centered horizontally, y=16, approximately 120px wide x 60px tall (scaled proportionally from world bounds) |
| Macro-map room scale | 4x-6x larger than mini-map scale; compute to fit ~120px width |
| Macro-map colors | Same as mini-map color table |
| Stats area | Below map, y = map_bottom + 16 |
| Stats content | `HP: {hp}/{max_hp}` palette 7, `JUICE: {juice}/{max_juice}` palette 11 |
| Ability icons | Row of unlocked ability indicators below stats (text abbreviations: `DSH`, `SHD`, `BST`, `RAM`, `CHG`) in palette 7 if unlocked, palette 1 if locked |
| Menu area | Below stats, y = stats_bottom + 16 |
| Menu layout | Vertical list: RESUME / SAVE (conditional) / QUIT, 12px spacing |
| Menu cursor | ">" palette 10, 8px left of text |
| Input | UP/DOWN cycle cursor, Z/ENTER confirms, ESC closes (same as RESUME) |
| Gamepad | D-pad up/down, A confirms, Start closes |

### 5. Death Sequence (`_update_death`, `_draw_death`)

| Property | Value |
|----------|-------|
| Freeze phase | 30 frames (0.5s): game world drawn frozen, no input processed |
| Fade phase | 30 frames (0.5s): black rectangle covers entire screen (`pyxel.rect(0, 0, SCREEN_W, SCREEN_H, 0)`) |
| Total duration | 60 frames (1 second) |
| After fade | Load last save via `SaveManager.load()` and `restore_from_save()`, set `game_state = "PLAYING"` |
| No save fallback | If no save file exists, set `game_state = "TITLE"` |
| No text | Death sequence has no text overlay -- purely visual |

### 6. Game State Machine

| State | Entry Condition | Update Behavior | Draw Behavior |
|-------|----------------|-----------------|---------------|
| `TITLE` | Game launch, or death with no save | Process title menu input | Title screen (cls black + text) |
| `PLAYING` | Select Continue/New Game, or unpause | Full gameplay update | Game world + HUD |
| `PAUSED` | Press ESC/Start during PLAYING | Process pause menu input | Frozen game world + pause overlay |
| `DEAD` | Player HP reaches 0 | Increment death_timer, trigger restore after 60 frames | Freeze + fade sequence |
| `WON` | (existing) | Existing win behavior | Existing win screen |

## Interaction Contracts

### Save Point Interaction Flow

1. Player walks onto save point entity (AABB overlap detected)
2. "SAVE?" prompt appears above save point in palette 10
3. Player presses UP -- save triggers via `SaveManager.save(game)`
4. "SAVED!" replaces "SAVE?" for 60 frames
5. Player walks away -- prompt disappears
6. If player presses UP again while still overlapping, save overwrites (no confirmation needed -- single slot)

### Pause Toggle Flow

1. Player presses ESC (keyboard) or Start (gamepad) during PLAYING state
2. `game_state` set to `PAUSED`, update returns immediately (no gameplay input processed)
3. Pause overlay renders on top of frozen game world
4. Player navigates menu with UP/DOWN + Z/ENTER
5. Selecting RESUME or pressing ESC again sets `game_state = "PLAYING"` and returns (consuming the unpause frame to prevent input bleed per Pitfall 4)

### Death Rollback Flow

1. Player HP reaches 0 -- `game_state` set to `DEAD`, `death_timer` set to 0
2. Frames 0-29: game world drawn frozen
3. Frames 30-59: black screen
4. Frame 60: `SaveManager.load()` called; if save exists, `reset()` then `restore_from_save(data)` then `game_state = "PLAYING"`
5. If no save: `game_state = "TITLE"`

### Title Screen Flow

1. On game launch: check `SaveManager.exists()`
2. If save exists: show CONTINUE (cursor=0) and NEW GAME (cursor=1)
3. If no save: show only NEW GAME (cursor=0)
4. CONTINUE: calls `reset()` then `restore_from_save(SaveManager.load())`, sets `game_state = "PLAYING"`
5. NEW GAME (when save exists): shows "ERASE SAVE AND START OVER?" confirmation; YES calls `SaveManager.delete()` then `reset()`, sets `game_state = "PLAYING"`
6. NEW GAME (when no save): calls `reset()`, sets `game_state = "PLAYING"`
