**`class Slider:`**
- `__init__(self, key, is_bool=False)`: Store key, query `tuning.get_baseline(key)` to get baseline value. Set `self.dragging = False`, `self.editing = False`, `self.edit_buffer = ""`, `self.flash_timer = 0`. Detect if baseline is `bool` type -> set `self.is_bool = True`. Detect if baseline is `int` type -> set `self.is_int = True`.
- `update(self, x, y, scroll_y, content_top, content_bottom)`: Takes the absolute y position of this row and scroll offset. Compute screen_y = y - scroll_y. If screen_y is outside [content_top, content_bottom], skip input. Handle three interaction zones:
  1. **Track area** (TRACK_X to TRACK_X+TRACK_W, screen_y to screen_y+ROW_H): On `pyxel.btnp(pyxel.MOUSE_BUTTON_LEFT)`, start drag. While `pyxel.btn(pyxel.MOUSE_BUTTON_LEFT)` and `self.dragging`, map mouse_x to value using log2 scale: `ratio = (mx - TRACK_X) / TRACK_W`, clamp [0,1], `multiplier = 2 ** (ratio * 4 - 2)` (maps 0->0.25x, 0.5->1x, 1->4x), `new_val = baseline * multiplier`. If `self.is_int`, round to int. Call `tuning.set_value(self.key, new_val)`. On `pyxel.btnr(MOUSE_BUTTON_LEFT)`, end drag.
  2. **Value area** (VALUE_X to VALUE_X+VALUE_W): On click, enter edit mode: `self.editing = True`, `self.edit_buffer = ""`.
  3. **Reset area** (RESET_X to RESET_X+RESET_W): On click, call `tuning.reset(self.key)`, set `self.flash_timer = 6`.
  If `self.editing`: read `pyxel.input_text` char by char, append digits/decimal/minus to `self.edit_buffer`. Enter confirms (parse float, `set_value`), Escape cancels, Backspace deletes last char. Decrement `self.flash_timer` if > 0.
- `draw(self, x, y, scroll_y, content_top, content_bottom)`: Compute screen_y = y - scroll_y. If screen_y + ROW_H < content_top or screen_y > content_bottom, skip draw (clipping). Draw:
  1. **Label**: `pyxel.text(LABEL_X, screen_y + 1, self.key[:12], TEXT_COLOR)` -- truncate to 12 chars.
  2. **Track**: Draw `pyxel.rect(TRACK_X, screen_y + 2, TRACK_W, 3, CONTENT_BG)` for background. Compute handle_x from current value using log2 scale (same as update). Baseline tick at TRACK_X + TRACK_W // 2. If handle < baseline_x: fill TRACK_BELOW_COLOR from handle to baseline. If handle > baseline_x: fill TRACK_ABOVE_COLOR from baseline to handle. Draw baseline tick: `pyxel.rect(baseline_x, screen_y + 1, 1, 5, BASELINE_TICK_COLOR)`. Draw handle: `pyxel.rect(handle_x - 1, screen_y, 3, ROW_H, HANDLE_COLOR)`.
  3. **Value**: Get current value from `getattr(tuning, self.key)`. If editing, show edit_buffer in EDIT_COLOR. Else show formatted value. Color: MODIFIED_VALUE_COLOR if current != baseline, else TEXT_COLOR.
  4. **Reset arrow**: Draw "<" glyph at RESET_X. Color: RESET_FLASH_COLOR if flash_timer > 0, else RESET_COLOR.

**`class CollapsibleGroup:`**

- `update(self, x, y, scroll_y, content_top, content_bottom)`: Compute screen_y = y - scroll_y. If click in header row (full 320px width, SUBGROUP_H tall), toggle `self.expanded`. If expanded, call `slider.update()` for each child with incrementing y.
- `draw(self, x, y, scroll_y, content_top, content_bottom)`: Draw header row: `pyxel.rect(0, screen_y, SCREEN_W, SUBGROUP_H, SUBGROUP_BG)`, glyph "v" or ">" at x+4, group name at x+12 in TEXT_SUBGROUP. If expanded, draw each child slider.

**`class TabBar:`**

All hit-testing must account for scroll offset. All `update()` methods must check `pyxel.mouse_y` is within content area bounds (CONTENT_Y to CONTENT_Y + CONTENT_H) before processing slider interactions.

**`_init_panel()`:** Called once on first `update()`. Build TabBar with ["Move", "Jump", "Slime", "Fuse"]. **`def is_editing() -> bool:`** Return True if any slider in the active tab is in keyboard edit mode. Used by main.py and preset hotkeys to suppress other key processing (Pitfall 4).

**`def update():`**
1. `global show_panel` -- toggle on `pyxel.btnp(pyxel.KEY_F1)`. Call `pyxel.mouse(show_panel)` on toggle.
2. If not show_panel, return immediately.
3. If not `_initialized`, call `_init_panel()`, set `_initialized = True`.
4. Call `_tabs.update()` for tab bar click handling. On tab switch (detect active change), reset `_scroll_y[new_tab]` to 0.
5. If `is_editing()`, skip all non-edit key processing (no preset hotkeys, no F-keys, no game keys).
6. Handle mouse wheel scroll: `pyxel.mouse_wheel`. Adjust `_scroll_y[active_tab]` by `wheel * 8` (8px per notch per UI-SPEC). Clamp between 0 and max_scroll (total content height - CONTENT_H, minimum 0).
7. Update all CollapsibleGroups in active tab, passing scroll offset and content bounds (CONTENT_Y, CONTENT_Y + CONTENT_H).

**`def draw():`**
1. If not show_panel, return.
2. Draw full-screen background: `pyxel.rect(0, 0, SCREEN_W, SCREEN_H, BG_COLOR)`.
3. Draw tab bar via `_tabs.draw()`.
4. Draw header bar (y=TAB_BAR_H, h=HEADER_H): Show "Slot N: alias" in TEXT_STATUS if a preset is active, else "Slot -: custom". Draw Save button on right side of header: `pyxel.rect(save_x, TAB_BAR_H, save_w, HEADER_H, SAVE_BTN_BG)` with "Save N" text.
5. Set clip to content area: `pyxel.clip(0, CONTENT_Y, SCREEN_W, CONTENT_H)`.
6. Draw each CollapsibleGroup in active tab with scroll offset. Track cumulative y starting at CONTENT_Y.
7. Reset clip: `pyxel.clip()`.
8. Draw footer bar (y=SCREEN_H - FOOTER_H, h=FOOTER_H): preset hints "[1] v1.3  [2] tight  [3] floaty" left-aligned, "Tab=slow" right-aligned. Both in TEXT_INACTIVE.

**`def set_active_preset(slot, alias):`** Update `_active_preset_slot` and `_active_preset_alias`. Called by presets module (Plan 02).

**`def get_active_preset_slot() -> int:`** Return `_active_preset_slot`. Called by presets module for save.
