  <name>Task 1: Full panel MVP verification -- all TOOL requirements</name>

  <action>
Human verifies the complete live-tuning panel MVP by running the game and testing all 11 verification steps below. No code changes -- pure verification checkpoint.

Run the game: `python main.py`

**1. Panel Toggle (TOOL-01, D-01):**
- Press F1 -- panel overlay should appear covering the full screen with dark navy background
- Game should continue running underneath (entities moving, animations playing)
- Press F1 again -- panel should close, cursor should disappear
- Verify 4 tabs visible: Move, Jump, Slime, Fuse

**2. Tab Navigation (TOOL-06, D-02):**
- Click each tab -- content should switch to that tab's sliders
- Move tab: should show movement (WALK_ACCEL, WALK_FRICTION, MAX_WALK_SPEED) and dash groups
- Jump tab: should show GRAVITY, JUMP_FORCE, etc. plus forgiving (COYOTE_TIME, JUMP_BUFFER) and wall groups
- Slime tab: should show slime_follow, slime_juice, projectile groups
- Fuse tab: should show drill, fusion, slime_ram, charge_shot, boost groups
- Verify NO non-feel groups visible (no health, hazards, tile, display, sprite, etc.)

**3. Collapsible Sub-Groups (D-04):**
- Click a sub-group header (e.g. "movement") -- should collapse, hiding its sliders
- Click again -- should expand
- Switch to Fuse tab -- only drill should be expanded, others collapsed
- Click to expand other Fuse sub-groups

**4. Slider Interaction (TOOL-02, TOOL-03, D-06, D-07, D-10):**
- Click and drag a slider handle (e.g. WALK_ACCEL on Move tab)
- Value should update in real-time -- close panel and verify walk speed feels different
- Slider track should show color split at baseline: dark grey (5) below, red (8) above
- Baseline tick mark should be visible at center of track
- Numeric value should turn red when different from baseline

**5. Keyboard Entry (D-09):**
- Click on a slider's numeric value label -- should enter edit mode (yellow text)
- Type a number (e.g. "0.2"), press Enter -- value should update
- Type and press Escape -- should cancel, value unchanged
- While editing, verify that pressing 1/2/3 does NOT load presets (input gating)

**6. Reset Arrow (TOOL-03, D-08):**
- Modify a slider, then click the green arrow -- value should snap to baseline
- Arrow should flash yellow briefly (6 frames)

**7. Scroll (Fuse tab):**
- On Fuse tab, expand all sub-groups -- should have ~26 sliders + 5 headers
- Mouse wheel should scroll the content area
- Verify sliders at the bottom are reachable

**8. Preset Loading (TOOL-04, D-11, D-12):**
- Press 1 -- header should show "Slot 1: v1.3", all values should reset to baseline
- Press 2 -- header should show "Slot 2: tight", walk speed should feel snappier
- Press 3 -- header should show "Slot 3: floaty", gravity should feel lighter
- Flip between 2 and 3 to feel the difference (A/B compare)

**9. Save (D-13, D-14):**
- Load slot 2, modify a slider
- Click Save button -- should write to slot_2.json
- Load slot 1, try to save -- should show "Overwrite baseline? Save again" warning in red
- Click again to confirm OR wait for it to cancel

**10. Slow-Mo (D-05):**
- Hold Tab key -- game entities should update at half speed
- Footer should show "SLOW" in yellow
- Release Tab -- full speed resumes, footer shows "Tab=slow"

**11. Journal (TOOL-05, D-16):**
- Make several slider edits
- Check `assets/journal/` directory -- should contain a session_YYYYMMDD_HHMMSS.jsonl file
- File should have one JSON line per edit with t, f, k, old, new fields
