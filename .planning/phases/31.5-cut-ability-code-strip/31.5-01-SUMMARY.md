- **Plan task order vs orchestrator system-prompt order:** The orchestrator's system-prompt listed substep order as bubble-shield first, charge-shot second, etc. PLAN.md and CONTEXT D-17 list ram first. - **`draw_sprite` import in projectile.py deletion:** After `ChargeProjectile.draw()` removal, the surviving `Projectile.draw()` only uses `pyxel.blt` (not `draw_sprite`). Dropped the unused import.
