**Part A: Feel Targets Document (per D-01, D-02, D-03)**

Create `.planning/phases/29-player-movement-feel-pass/29-FEEL-TARGETS.md` with a header noting these are DRAFT targets for user review. Use the v1.3 physics reference from RESEARCH.md to calculate pass/fail criteria.

The document must contain three sections -- Ground, Air, Wall -- each with a table using columns: ID | Test | Pass Condition | Fail Condition.

Ground targets (prefix M-G):
- M-G01: Accel responsiveness -- "From standstill, reach max speed" -- Pass: within 10 frames (167ms) -- Fail: >15 frames (sluggish) or <4 frames (twitchy)
- M-G02: Stop distance -- "Release walk at max speed" -- Pass: stop within 9 frames (150ms) -- Fail: >14 frames (ice skating) or <3 frames (wall-of-friction)
- M-G03: Run corridor feel -- "Run 20-tile corridor" -- Pass: feels responsive to input changes, direction reversal smooth -- Fail: sluggish direction changes or uncontrollable

Air targets (prefix M-A):
- M-A01: 3-tile gap from standing -- "Jump a 3-tile gap without running start" -- Pass: clear with 0.5+ tiles margin -- Fail: requires running start
- M-A02: 4-tile gap at full speed -- "Jump 4-tile gap with running start + full hold" -- Pass: land 1+ tile in -- Fail: fall short
- M-A03: 5-tile gap at full speed -- "Jump 5-tile gap at max speed + full hold" -- Pass: clear or just barely miss (0.08 tiles = 1.3px) -- Fail: clear by >1 tile (too far) or miss by >0.5 tile (too short)
- M-A04: Variable jump min height -- "Tap jump (instant release)" -- Pass: reach 0.8-1.2 tiles -- Fail: <0.5 tiles (useless) or >2 tiles (no control)
- M-A05: Full jump max height -- "Hold jump fully" -- Pass: reach 3.5-4.2 tiles -- Fail: <3 tiles or >5 tiles
- M-A06: Coyote time -- "Walk off ledge, jump within 12 frames" -- Pass: jump executes -- Fail: falls
- M-A07: Coyote boundary -- "Walk off ledge, jump at frame 13+" -- Pass: falls (no jump) -- Fail: jump still works (too generous)
- M-A08: Jump buffer -- "Press jump 8 frames before landing" -- Pass: jump triggers on land -- Fail: no jump
- M-A09: Apex hang -- "At jump peak, hold direction" -- Pass: brief floaty hang before descent -- Fail: sharp velocity reversal at apex

Wall targets (prefix M-W):
- M-W01: Wall slide speed -- "Slide down 6-tile wall" -- Pass: noticeably slower than free fall -- Fail: same speed as free fall or barely moving
- M-W02: Wall jump ascent -- "Wall jump up 3-tile shaft" -- Pass: gain at least 1.5 tiles height per jump -- Fail: lose height each jump
- M-W03: Wall jump zigzag -- "Alternate wall jumps in 3-tile wide shaft" -- Pass: can ascend steadily -- Fail: X impulse overshoots wall or undershoots

Note at bottom: "These targets are DRAFT -- calculated from v1.3 baseline physics. User must review and approve before tuning begins."
