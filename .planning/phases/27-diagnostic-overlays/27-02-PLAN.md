**`init(game)` function** — subscribe to event bus for blip placement. Use lazy init pattern to prevent duplicate subscriptions (Pitfall 5 from RESEARCH.md). Store game reference for blip position recording:
```python
_game_ref = None

def init(game):
    global _initialized, _game_ref
    if _initialized:
        return
    _game_ref = game
    event_bus.subscribe("fall_start", _on_fall_start)
    event_bus.subscribe("jump_start", _on_jump_start)
    event_bus.subscribe("land", _on_land)
    _initialized = True
```

**Event callbacks** — record world-space positions at the moment events fire:
```python
def _on_fall_start():
    """Record where player left the ground (coyote trigger point)."""
    if _game_ref is None:
        return
    p = _game_ref.player
    _coyote_blips.append((p.x + p.w // 2, p.y + p.h, pyxel.frame_count))

def _on_jump_start():
    """Record where player pressed jump."""
    if _game_ref is None:
        return
    p = _game_ref.player
    _jump_blips.append((p.x + p.w // 2, p.y + p.h, pyxel.frame_count))

def _on_land():
    """Record where player landed."""
    if _game_ref is None:
        return
    p = _game_ref.player
    _land_blips.append((p.x + p.w // 2, p.y + p.h, pyxel.frame_count))
```

**`_draw_slime_overlay(game)`** — per D-05 and UI-SPEC F5 contract:

Breadcrumb trail from `game.slime.history` deque:
- Iterate `enumerate(s.history)` — DO NOT modify the deque.
- Color by index: 0-10 = palette 11 (green), 11-20 = palette 3 (dark green), 21+ = palette 5 (dark grey).
- Draw each point with `pyxel.pset(hx, hy, color)`.

Distance threshold circles centered on player:
- `pyxel.circb(player_cx, player_cy, int(tuning.SLIME_MAX_DIST), 8)` — red
- `pyxel.circb(player_cx, player_cy, int(tuning.SLIME_REFORM_DIST), 10)` — yellow
- `player_cx = p.x + p.w // 2`, `player_cy = p.y + p.h // 2`

Follow target point:
- `pyxel.circ(s.target_x, s.target_y, 1, 14)` — pink dot (radius 1)

Stuck detection indicator:
- Update `_slime_stuck_frames` inside `_draw_slime_overlay()` since the counter is overlay-internal state, not entity state.
  - `vel_mag = (s.dx**2 + s.dy**2) ** 0.5`
  - If `vel_mag < STUCK_VEL_THRESHOLD`: increment `_slime_stuck_frames`
  - Else: reset `_slime_stuck_frames = 0`
- When `_slime_stuck_frames > STUCK_FRAME_THRESHOLD`: draw flashing X at slime center. Flash = only draw on even `pyxel.frame_count` frames. X = two crossed lines, 4px each arm, palette 8 (red):
  ```python
  scx, scy = s.x + s.w // 2, s.y + s.h // 2
  if pyxel.frame_count % 2 == 0:
      pyxel.line(scx - 4, scy - 4, scx + 4, scy + 4, 8)
      pyxel.line(scx + 4, scy - 4, scx - 4, scy + 4, 8)
  ```

Catch-up state indicator:
- When slime velocity magnitude > STUCK_VEL_THRESHOLD and distance to target > tuning.SLIME_REFORM_DIST: draw a small arrow from slime center toward target point, palette 12 (blue). Arrow = `pyxel.line(scx, scy, scx + dx_norm * 6, scy + dy_norm * 6, 12)` where dx_norm/dy_norm is the normalized direction to target, scaled to 6px length.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Overlay -> Entity state | Overlay reads entity attributes — must never write |
| Event bus -> Overlay callbacks | Callbacks execute synchronously in game frame — must be fast and non-mutating |
| Overlay -> tuning values | Read-only access to distance thresholds |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Tampering | overlays.py draw functions | mitigate | All entity access is read-only attribute access; no setter calls, no method calls that mutate state. Tests verify no mutation. |
| T-27-02 | Denial of Service | Blip deque unbounded growth | mitigate | Pre-allocated deque(maxlen=32) for all blip buffers prevents unbounded memory growth |
| T-27-03 | Denial of Service | Event bus duplicate subscriptions | mitigate | Lazy init with `_initialized` flag prevents duplicate subscriptions on re-import or multiple init calls |
| T-27-04 | Information Disclosure | Debug overlay in production | accept | Single-developer prototype debug tool; no production deployment. F-key toggles intentionally accessible. |
| T-27-05 | Denial of Service | Stuck detection counter overflow | accept | Integer counter increments at 60fps; would take ~1.1 years to overflow Python int. No practical risk. |
</threat_model>
