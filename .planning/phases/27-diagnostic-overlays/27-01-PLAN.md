**`update()` function** — toggle F2-F5 flags (no Ctrl modifier, unlike debug.py). Also call `_update_frame_time()` every frame to keep the ring buffer current even when F3 is off:
```python
def update():
    global show_hitboxes, show_velocity, show_input, show_slime
    if pyxel.btnp(pyxel.KEY_F2):
        show_hitboxes = not show_hitboxes
    if pyxel.btnp(pyxel.KEY_F3):
        show_velocity = not show_velocity
    if pyxel.btnp(pyxel.KEY_F4):
        show_input = not show_input
    if pyxel.btnp(pyxel.KEY_F5):
        show_slime = not show_slime
    _update_frame_time()
```

**`_update_frame_time()`** — record frame delta in milliseconds using `time.perf_counter()`:
```python
def _update_frame_time():
    global _last_frame_time
    now = time.perf_counter()
    if _last_frame_time > 0:
        delta_ms = (now - _last_frame_time) * 1000.0
        _frame_times.append(delta_ms)
    _last_frame_time = now
```

**`draw(game)` function** — called in world-space (camera still set). Draw order per UI-SPEC: F5 slime first (large circles behind), F2 hitboxes, F3 velocity, F4 input blips last. Only draw if flag is True:

```python
def draw_indicator():
    if not any([show_hitboxes, show_velocity, show_input, show_slime]):
        return  # No indicator when all overlays off
    labels = [("F2", show_hitboxes), ("F3", show_velocity), ("F4", show_input), ("F5", show_slime)]
    # Background bar
    bar_w = len(labels) * 16 + 4  # ~68px
    pyxel.rect(0, 0, bar_w, 10, 1)
    x = 2
    for label, active in labels:
        color = 7 if active else 13
        pyxel.text(x, 2, label, color)
        x += 16
```
