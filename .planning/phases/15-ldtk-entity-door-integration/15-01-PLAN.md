**A. Direction normalization in map.py (INT-03, per D-01, D-02)**

In `src/level/map.py`, `load_from_ldtk_simplified()`, replace lines 82-84:
```python
for key, val in inst.get("customFields", {}).items():
    ent_data[key] = val
```
With:
```python
for key, val in inst.get("customFields", {}).items():
    # Normalize string enum values to lowercase (D-01, D-02)
    if isinstance(val, str):
        ent_data[key] = val.lower()
    else:
        ent_data[key] = val
```

This normalizes ALL string fields from customFields (direction, action, and any future enum fields) to lowercase at parse time. Non-string values (ints like target_level_id, hp) are left unchanged.
