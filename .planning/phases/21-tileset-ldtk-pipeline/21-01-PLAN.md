**1. File moves (per D-04, D-07):**
- Copy `assets/tiles.png` -> `assets/tilesets/cavern.png` (overwrite existing)
- Copy `assets/tiles.aseprite` -> `assets/tilesets/cavern.aseprite`

**2. Patch output.ldtk JSON (per D-08, D-09, D-11):**
Use `json.load/dump` with `indent=1` (match LDtk's format) or `indent=2`.

Top-level:
- `defaultGridSize`: 8 -> 16

Tileset definitions (`defs.tilesets`):
- For tileset with `uid=64` (identifier "Tiles"):
  - `relPath`: current value -> `"tilesets/cavern.png"` (per D-06)
  - `pxWid`: 96 -> 256
  - `pxHei`: 80 -> 256
  - `tileGridSize`: 8 -> 16
  - `__cWid`: 12 -> 16
  - `__cHei`: 10 -> 16
  - `cachedPixelData`: set to `None`/null (LDtk regenerates on open)
  - `savedSelections`: clear to `[]`
- For tileset with `uid=61` (identifier "Tileset", old tileset.png):
  - Update `relPath` to `"tilesets/cavern.png"` (file is deleted, but ref shouldn't be broken)
  - Or remove the tileset def entirely if no layers reference uid=61

Layer definitions (`defs.layers`):
- IntGrid layer (uid=2): `gridSize`: 8 -> 16
- Entities layer (uid=1): `gridSize`: 8 -> 16

Auto-rule tileRectsIds (within `defs.layers` IntGrid `autoRuleGroups`):
- For each rule in each group, recalculate `tileRectsIds` array values:
  ```python
  OLD_COLS = 12  # old tileset was 96px / 8px = 12 columns
  NEW_COLS = 16  # new tileset is 256px / 16px = 16 columns
  old_col = old_id % OLD_COLS
  old_row = old_id // OLD_COLS
  new_id = old_row * NEW_COLS + old_col
  ```
- Pattern values (the neighbor-match arrays) stay unchanged

Level instances (`levels[]`):
- For each level's `layerInstances`:
  - **autoLayerTiles**: Filter to keep only tiles where BOTH `px[0] % 16 == 0` AND `px[1] % 16 == 0`. For surviving tiles, multiply `src[0]` and `src[1]` by 2. Do NOT modify `px` values.
  - **intGridCsv**: If present as flat array, reshape to 2D using old width (40 columns), take every-other-row and every-other-column (stride 2), flatten back. New dimensions: 20x11 per standard room. For non-standard rooms, use `level.pxWid // 8` as old width and `level.pxWid // 16` as new width.
  - **entityInstances**: Snap `px` array values to nearest 16px: `round(val / 16) * 16` (per D-13, D-14). Also snap `__worldX`/`__worldY` if present. Update `__grid` values: `[round(px[0]/16), round(px[1]/16)]`.
  - Update layer `__gridSize`: 8 -> 16
  - Update layer `__cWid` and `__cHei` to reflect new grid (pxWid//16, pxHei//16)

**3. Patch simplified exports (per D-17, D-18, D-19):**
For each level directory in `assets/output/simplified/Level_*`:
- `IntGrid.csv`: Read rows, take every-other-row (stride 2 starting at row 0), within each kept row take every-other-value (stride 2 starting at col 0). Write back. Result: 20 values x 11 rows for standard rooms.
- `data.json`: Snap entity positions to nearest 16px (same rounding as output.ldtk). Pixel dimensions (width/height) stay unchanged (320x176).

**4. Patch entity-schema.json (per D-05):**
- Change `biomes.cavern.tileset` from `"assets/tiles.png"` to `"assets/tilesets/cavern.png"`
