# Plan 05-01: Player Health System

Implement the foundational health, damage, and invulnerability systems for the player.

## User Review Required

> [!IMPORTANT]
> - Spikes will now deal 1 HP damage and respawn the player at the room start position, instead of instant death.
> - Contact with the Boss or Enemies will deal 1 HP damage and trigger knockback.

## Proposed Changes

### Core Constants (`src/core/constants.py`)
- Add `PLAYER_MAX_HP = 3`.
- Add `INVULN_DURATION = 60`.
- Add `KNOCKBACK_FORCE_X = 2.0`.
- Add `KNOCKBACK_FORCE_Y = -2.5`.

### Player Entity (`src/entities/player.py`)
- **State:** Add `hp`, `max_hp`, `invuln_timer`, `knockback_timer`.
- **Method `take_damage(amount, source_x)`**:
    - Subtract HP.
    - Set `invuln_timer`.
    - Apply knockback impulse (dx, dy).
    - Trigger `die()` if `hp <= 0`.
- **Update Logic**:
    - Decrement `invuln_timer`.
    - If `invuln_timer > 0`, ignore damage but NOT hazards.
    - In `move_and_collide`, update hazard collision to call `take_damage` and respawn at room entrance.

### Game Controller (`main.py`)
- Update UI to draw hearts (color 8).
- Update death logic to only trigger when `player.hp <= 0`.
- Track `room_spawn_x/y` for hazard respawn.

## Verification Plan

### Automated Tests
- `test_player_damage`: Verify HP reduction.
- `test_invulnerability`: Verify player ignores damage while `invuln_timer > 0`.
- `test_death_at_zero_hp`: Verify player dies only when HP hits zero.
- `test_hazard_damage`: Verify hazard deals damage and resets position.

### Manual Verification
- Touch a spike: should lose 1 HP and teleport to room entrance.
- Touch the Mole boss: should lose 1 HP, get knocked back, and flash.
